# 🎵 TerPlayer

A terminal-based music player that lets you search and stream music directly from your terminal.

## Features

- 🔎 Search for songs
- 🎵 Stream music directly from the internet
- ⏯️ Play and control tracks
- ⌨️ Keyboard-based controls
- 🚫 No music is permanently downloaded

## Installation

Requires [yt-dlp](https://github.com/yt-dlp/yt-dlp) on your PATH (macOS: `brew install yt-dlp`).

Run directly with:

```bash
npx terplayer

```
